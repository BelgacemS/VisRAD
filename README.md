# VisRAD

Defect detection on industrial parts when defects are rare.

## Problem

Defective parts are rare and varied. The question is at what rarity level an unsupervised anomaly detector becomes preferable to a supervised detector, and how to set a reject threshold from the costs of false negatives and false positives.
