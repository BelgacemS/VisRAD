# VisRAD

Defect detection on industrial parts when defects are rare. Course project for "Analyse et restitution" (M1, Université Paris Cité).

## Problem

Defective parts are rare (less than 1% of production) and varied. The question is at what rarity level an unsupervised anomaly detector becomes preferable to a supervised detector, and how to set a reject threshold from the costs of false negatives and false positives.

## Data

[VisA](https://github.com/amazon-science/spot-diff) (12 categories, 10,821 images of which 1,200 are defective, CC BY 4.0). Images are not stored in this repository; they will be fetched by a download script.
