# VisRAD

Visual Rare Anomaly Detection Benchmark.

## Problem

Anomalies are rare and varied. The question is at what rarity level an unsupervised anomaly detector becomes preferable to a supervised detector, and how to set a reject threshold from the costs of false negatives and false positives.
